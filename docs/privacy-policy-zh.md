# Audio Doctor 隐私政策

最后更新：2026-11-10

Audio Doctor 以本地处理为原则。应用不内置广告 SDK、不收集用户身份信息、不收集联系人、位置、照片或浏览记录，也不会把你的音频上传到开发者服务器。

## 本地处理

- 音频分析在本机完成。
- 音频修复在本机完成。
- CSV / HTML / JSON 报告保存在你选择的输出文件夹。
- 原始音频不会被覆盖，处理结果会写入新文件。

## 本地记录

应用可能使用 macOS 本地偏好设置保存界面状态或内测解锁状态。这些数据保留在本机，不用于身份追踪。

## 权限说明

- 文件访问仅用于读取你主动拖入或选择的音频。
- 导出仅写入你通过系统保存面板选择的路径。
- 应用不申请麦克风、摄像头、位置或通讯录权限。

## 第三方服务

当前应用不集成广告、统计或第三方数据收集服务。若未来版本增加可选云处理，会在功能入口明确说明并单独请求同意。

## 联系

如对隐私政策有疑问，请通过 GitHub 仓库 issue 联系开发者。
