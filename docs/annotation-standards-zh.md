# Audio Doctor 客观标注标准

这份标准给标注团队使用，目标是把「普通标注员靠主观听感很难稳定判断」的技术问题拆成可复查的数据。它不是音乐审美评分，也不能完全替代最终人工试听。

## 总等级

| 等级 | 判定 | 使用建议 |
|---|---|---|
| A | 无失败项、无复核项 | 可直接标注 |
| B | 无失败项，有个别复核项 | 可标注，复核项写进备注 |
| C | 无失败项，但有 2 项以上边界风险 | 建议技术复核后再标注 |
| D | 存在明显技术异常 | 先修复或退回，不建议直接标注 |

## 1. 响度

### 综合响度 LUFS

- 通过：`-16 ～ -12 LUFS`
- 复核：`-20 ～ -16` 或 `-12 ～ -9`
- 异常：低于 `-20` 或高于 `-9`
- 推荐中心：`-14 LUFS`

说明：LUFS 更接近人耳感知的响度。标注员容易把小音量误判成内容弱、演唱没力、混音差，所以需要先看 LUFS。

### RMS 电平

RMS 用于观察平均能量，和 LUFS 的用途不同。RMS 偏低不一定错误，但如果 LUFS 与 RMS 同时偏低，说明整体响度不足。

## 2. 峰值、削波与失真

### 真峰 True Peak

- 通过：`≤ -1.0 dBTP`
- 复核：`-1.0 ～ 0 dBTP`
- 异常：`> 0 dBTP`

说明：普通样本峰值可能看不到采样点之间的真实峰值。真峰更能预测转码、播放器限幅和后续失真风险。

### 削波采样占比

- 通过：`≤ 0.001%`
- 复核：`0.001% ～ 0.05%`
- 异常：`> 0.05%`

说明：削波通常表现为破音、发毛、发硬。标注员听感上可能只说“刺”或“脏”，但难以判断严重程度。

### 直流偏移

- 通过：绝对值 `≤ 0.001`
- 复核：`0.001 ～ 0.005`
- 异常：`> 0.005`

说明：直流偏移会浪费 headroom，也会影响 RMS 与相位判断。

## 3. 动态

### 峰值因子 / Crest Factor

- 通过：`4.5 ～ 14 dB`
- 复核：`3 ～ 4.5 dB` 或 `14 ～ 18 dB`
- 异常：低于 `3 dB` 或高于 `18 dB`

说明：过低通常代表过度压缩或过度限幅，听感容易“平、堵、没有起伏”。过高则要检查弱段落是否太小。

## 4. 相位、声道平衡与空间兼容

### 相位相关性

- 通过：`0.25 ～ 0.90`
- 复核：`0.05 ～ 0.25` 或 `> 0.90`
- 异常：`< 0.05`，特别是负值

说明：负相关代表左右声道明显反相，单声道播放时可能严重抵消。标注员很难靠普通耳机稳定发现这个问题。

### 左右声道电平差

- 通过：`≤ 1 dB`
- 复核：`1 ～ 3 dB`
- 异常：`> 3 dB`

说明：正值代表左声道更响，负值代表右声道更响。声道不平衡会影响声像判断。

### 单声道折叠损失

- 通过：`≥ -1 dB`
- 复核：`-3 ～ -1 dB`
- 异常：`< -3 dB`

说明：该指标衡量立体声转单声道时损失多少能量。损失越大，说明相位抵消越严重。

### 空间展开指数

- 通过：`≥ 70`
- 复核：`45 ～ 69`
- 异常：`< 45`

说明：由立体声宽度和相位安全度组成。它描述客观空间信息，不代表音乐空间感是否好听。

## 5. 频段平衡

### 低频 / 身体感能量

- 通过：20～350Hz 能量占比 `15% ～ 50%`
- 复核：低于 `15%` 或高于 `50%`

说明：低频不足常被主观描述为“薄、假、飘、没有身体感”。这个指标能让标注员区分音量问题和频段结构问题。

### 高频噪声占比

- 通过：`≤ -18 dB`
- 复核：`-18 ～ -12 dB`
- 异常：`> -12 dB`

说明：统计 9kHz 以上能量占比，用于提示沙沙声、嘶声或高频伪影。

### 疑似 AI 感指数

- 通过：`≤ 35`
- 复核：`35 ～ 65`
- 异常：`> 65`

说明：这是启发式指数，由低频偏薄和高频噪声占比推得。它不是公认心理声学指标，不能当作最终判决。

## 6. 内容类型与音乐结构参考

### 是否音乐与人声状态

- 可采用：音乐置信度 ≥70%，且人声状态与试听一致。
- 复核：音乐置信度 45%～69%，或人声状态为“疑似人声 / 背景和声需复核”。
- 换流程：音乐置信度 <45%，或确认为非音乐内容。

说明：内容类型判断来自节拍、音高、持续度和人声频段线索。说唱、和声、电子人声、器乐拟人声容易误判，必须人工复核低置信度结果。

### 调性、转调、节拍与和弦

- 调性输出主音、大调/小调、候选调和置信度；置信度低于 50% 时仅作提示，不作为标注结论。
- 转调输出局部调性、原调性、目标调性、时间范围与置信度；界面标注“疑似”时，标注员必须人工确认边界。
- BPM 来自 onset 包络自相关；置信度低于 50% 或散板/慢歌应人工打拍确认。
- 拍号仅作为低置信度参考，不能直接替代乐谱或人工判断。
- 速度 / 拍号变化只提示局部估计与全曲不同；复杂鼓点、渐快渐慢、复节奏和编辑切片会降低可靠性。
- 和弦功能为近似分析，仅输出和弦、级数和主 / 下属 / 属功能；复杂编曲、转位、低音不清、多乐器重叠时必须人工复核。
- 配器角色来自频段、瞬态、持续度与立体声线索，只判断“主奏/辅助/低频/节奏/氛围”等角色，不等同于源分离或精确乐器识别。

## 7. AI 伪影七维指标

以下指标是可解释的信号启发式，用于统一标注口径和排序复核，不用于判断音频来源，也不能作为规避检测的工具。单项阈值为：≤45 通过，45～70 复核，>70 异常。

| 指标 | 计算口径 | 通过 | 复核 | 异常 |
| --- | --- | --- | --- | --- |
| 高频沙声 | 9kHz 以上能量占比映射 | ≤45 | 45～70 | >70 |
| 金属闪烁 | 高频能量与频谱平坦度组合 | ≤45 | 45～70 | >70 |
| 频谱空洞 | 相邻频带低于局部中位数的程度 | ≤45 | 45～70 | >70 |
| 频段偏薄 | 20～350Hz 能量不足程度 | ≤45 | 45～70 | >70 |
| 相位不稳定 | 分窗相位相关性的波动与低相关窗口 | ≤45 | 45～70 | >70 |
| 瞬态模糊 | 包络块间攻击变化不足 | ≤45 | 45～70 | >70 |
| 立体声异常 | 左右平衡、单声道折叠损失与低相关组合 | ≤45 | 45～70 | >70 |
| AI 伪影总分 | 以上七项加权 | ≤45 | 45～70 | >70 |

### 时间轴 Badcase

- 每个可疑窗口输出开始时间、结束时间、问题类型、严重度、证据、置信度与建议。
- 存在高严重度窗口：技术等级直接标异常。
- 无高严重度且中严重度窗口 ≥2：标复核。
- 标注员必须优先试听定位区间；若客观证据与主观听感冲突，以试听结论为准并记录原因。

## 8. 批量任务分派建议



1. 先跑「只分析 / 标注报告」，不修改音频。
2. A/B 等级交给普通标注员。
3. C 等级交给资深标注员或音频技术员复核。
4. D 等级先进入技术修复或退回流程。
5. CSV 报告随任务一起归档，方便质量追溯。
6. 对涉及“空间感”“失真”“响度”的标注项，必须引用客观数据，不只写主观听感。
