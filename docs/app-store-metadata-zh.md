# Audio Doctor Mac App Store 素材草案

## 应用名称

Audio Doctor

## 副标题

AI 音频体检与音乐标注

## 关键词

音频分析,音乐标注,LUFS,调性,BPM,和弦,AI 音频,音频修复,相位,批量质检

## 一句话介绍

给 AI 生成音乐和批量音频做本地体检、音乐结构分析与轻量修复。

## 描述

Audio Doctor 是一个本地优先的音频质检、标注与修复工作台，适合 AI 音乐创作者、音频标注团队和内容审核人员。

主要能力：

1. 五大类标注工作台
   - 内容判断：是否音乐、纯音乐 / 带人声
   - 音乐结构：调性、转调、BPM、拍号变化、和弦功能、配器角色
   - 技术质量：响度、真峰、削波、相位、立体声宽度、AI 伪影
   - 时间定位：按秒定位可疑区间
   - 标确切认：异常项、复核项与人工确认建议

2. AI 音频修复
   - 高频沙声抑制
   - 低频身体感补偿
   - 低频相位稳定
   - 瞬态恢复
   - 响度标准化与真峰保护
   - Suno 人声 / Suno 流行等内容预设

3. 批量质检
   - 递归扫描大量音频
   - 输出 CSV / HTML 报告
   - 按严重程度排序 badcase
   - 中途取消不丢已完成记录

4. 声道与空间格式
   - 立体声与单声道互转
   - 立体声转 5.1
   - 立体声转一阶 AmbiX

音频在本机处理，不上传服务器，原始文件不会被覆盖。

说明：调性、转调、和弦、拍号、配器和 AI 感为启发式分析，用于辅助人工标注，不等于精确乐谱或最终听感判决。AmbiX 不是 Dolby Atmos。

## 审核备注

App 启动后无需账号即可使用。审核时可直接拖入任意 WAV / MP3 / M4A 音频，先进入「标注工作台」查看分析结果，再进入「修复工作台」选择导出路径。App 只写入用户明确选择的导出位置，不收集用户数据。

## 隐私政策要点

- 不收集音频文件
- 不收集联系人、位置或浏览记录
- 不上传音频到服务器
- 分析、修复和报告均在用户本机完成
- 用户主动导出的报告仅保存在用户选择的文件夹
